# Pocket Chaos PoC

Static production build of the Angular sandbox (`Pocket_Chaos/PoC/pocket-chaos-poc`). GitHub Pages serves this repository root.

The app is built with `<base href="/pocket-chaos-poc/">`, so the site URL is https://eddenn.github.io/pocket-chaos-poc/. `.nojekyll` keeps Pages from turning the root into a Jekyll site. `404.html` is a copy of `index.html` so an unknown path still loads the app.
